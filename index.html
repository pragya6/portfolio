CRM Agent

LangGraph · FastAPI · Supabase · Gradio · HF Spaces

An agent that can update and delete CRM records needs safety that does not depend on the prompt. So the approval gate lives in code: a LangGraph interrupt that pauses every sensitive action for a human, whatever the model decides to say.

Built
  • Stateful LangGraph agent orchestrating 6 CRM tools with structured JSON outputs.
  • Human-in-the-loop approval gates for sensitive actions, enforced at the graph level rather than in the system prompt.
  • Classified error recovery: retry-with-backoff plus an iteration circuit breaker, with structured JSON logging and cost tracking.
Measured
  • A 50-query evaluation harness comparing guardrails off against on, three runs each, fully stable across runs.
  • 13/14 sensitive actions gated — every action that reached the gate was correctly caught. The one miss never reached it, because the agent picked the wrong tool, so no interrupt fired.
  • Guardrails lifted tool selection and parameter extraction to 100%.

Selected work · Grounded RAG

Homoeo Quiz

Python · Gemini 2.5 Flash-Lite · ChromaDB · sentence-transformers · HF Spaces

A strict-grounding question-answering system over a fixed canonical corpus, where every answer and explanation has to cite a source passage. The interesting part is not the retrieval — it is the harness that proves the system is not making things up.

Built
  • Hybrid architecture — local embeddings (bge-small) with remote generation (Gemini 2.5 Flash-Lite) — a deliberate cost, latency and rate-limit trade-off.
  • A guardrail that refuses to answer when the source material does not cover a topic, rather than improvising.
  • An automated evaluation harness reporting Wilson 95% confidence intervals.
Measured
  • Hallucination rate held at 0.0 and quote validity at 1.0 across 102 served queries.
  • Correct refusals 27/27, while over-refusing only 2.9% of the time.
  • Retrieval hit@k of 0.87 (n=30) at a p50 latency of roughly 2.0s.
